# 🧮 Spring Boot Calculator

A simple Calculator web application built using **Spring Boot**, **Spring MVC**, **JSP**, and **Maven**.

The application allows users to enter two numbers and calculates their sum through a clean web interface following the MVC architecture.

## 🚀 Features

* Add two numbers
* Spring MVC Architecture
* JSP-based Views
* Form Handling using `@RequestParam`
* Result Display using `ModelAndView`
* Custom CSS Styling

## 🛠️ Tech Stack

* Java 21
* Spring Boot
* Spring MVC
* JSP
* Maven
* HTML
* CSS

## ▶️ Run the Application

Clone the repository:

```bash
git clone https://github.com/your-username/spring-boot-calculator.git
```

Navigate to the project folder:

```bash
cd spring-boot-calculator
```

Run the application:

```bash
mvn spring-boot:run
```

Open in browser:

```text
http://localhost:8080/
```
